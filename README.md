# 🎈 Μαθαίνω Παίζοντας

Ψηφιακός βοηθός μάθησης με εκπαιδευτικά παιχνίδια για τις πρώτες τάξεις του Δημοτικού
(Α'–Δ'), στα Ελληνικά.

## Τι περιλαμβάνει

- **Σύνδεση εκπαιδευτικού** (email + κωδικός) με ασφαλές session.
- **Μαθήματα**: Γλώσσα, Μαθηματικά, Αγγλικά — ανά τάξη (Α'–Δ').
- Σε κάθε μάθημα: **μαθητές**, **σημειώσεις μαθήματος**, **παιχνίδια** και
  **αποτελέσματα/βαθμολογίες**.
- **3 παιχνίδια ανά μάθημα** (9 συνολικά), με δυσκολία που προσαρμόζεται στην τάξη:
  - Γλώσσα: Λέξη & Εικόνα, Συμπλήρωσε το Γράμμα, Μνήμη Συλλαβών
  - Μαθηματικά: Πρόσθεση & Αφαίρεση, Αντιστοίχιση Αριθμών, Μέτρημα Σχημάτων
  - Αγγλικά: Word & Picture, Μετάφραση Quiz, English Memory
- Στο μάθημα Γλώσσας υπάρχουν επιπλέον **Ενότητες Λεξιλογίου** (Ζώα, Σπίτι &
  Οικογένεια, Φύση, Φαγητό, Σχολείο), καθεμία με 4 μικρά παιχνίδια: Βρες το
  Γράμμα, Λέξη & Εικόνα, Λείπει ένα Γράμμα, Άκου και Βρες (με εκφώνηση λέξης).
- Όλα τα δεδομένα (εκπαιδευτικοί, μαθητές, βαθμολογίες, σημειώσεις) αποθηκεύονται
  μόνιμα σε βάση δεδομένων **PostgreSQL** μέσω **Prisma**.

## Τεχνολογίες

Next.js (App Router) · TypeScript · Tailwind CSS · Prisma · PostgreSQL · JWT sessions (jose) · bcrypt

## Τοπική εκτέλεση

1. Αντίγραψε το `.env.example` σε `.env` και συμπλήρωσε τη σύνδεση με τη βάση
   δεδομένων σου (Postgres) και ένα τυχαίο `JWT_SECRET`.
2. Εγκατάσταση εξαρτήσεων:
   ```bash
   npm install
   ```
3. Δημιουργία των πινάκων στη βάση:
   ```bash
   npx prisma db push
   ```
4. Εκκίνηση:
   ```bash
   npm run dev
   ```

## Deployment στο Vercel

1. Σύνδεσε το repository με ένα νέο project στο Vercel.
2. Στο tab **Storage**, πρόσθεσε μια βάση **Postgres** (π.χ. μέσω Neon) — αυτό θα
   ορίσει αυτόματα τις μεταβλητές `POSTGRES_PRISMA_URL` και
   `POSTGRES_URL_NON_POOLING`.
3. Πρόσθεσε τη μεταβλητή περιβάλλοντος `JWT_SECRET` με μια τυχαία, μεγάλη τιμή.
4. Deploy. Το build script τρέχει αυτόματα `prisma generate`· μετά το πρώτο deploy,
   τρέξε `npx prisma db push` (με το production `DATABASE_URL`) για να δημιουργηθούν
   οι πίνακες.

## Δραστηριότητες εκπαιδευτικού (δημιουργός παιχνιδιών)

Από το μενού **✨ Δραστηριότητες** ο εκπαιδευτικός φτιάχνει μόνος του δικό του
υλικό, χωρίς κώδικα, με οδηγό τριών βημάτων (τύπος → περιεχόμενο → δοκιμή και
αποθήκευση). Υποστηρίζονται: πολλαπλής επιλογής, συμπλήρωση κενού, ανοιχτού
τύπου, σταυρόλεξο (το πλέγμα φτιάχνεται αυτόματα), τροχός, παιχνίδι μνήμης και
αυτόματες πράξεις.

- Οι δραστηριότητες αποθηκεύονται στη βάση (πίνακας `Activity`) και μπορούν να
  συνδεθούν με ένα μάθημα. Παίζονται με επιλεγμένο μαθητή από τη σελίδα του
  μαθήματος ή από τη λίστα δραστηριοτήτων.
- Στα τεστ (πολλαπλής επιλογής, συμπλήρωση κενού, πράξεις) υπάρχει **άμεση
  ανατροφοδότηση** μετά από κάθε απάντηση και, στο τέλος, **αναλυτικό
  αποτέλεσμα**: ποσοστό, σωστά με την πρώτη και ανασκόπηση κάθε ερώτησης. Η
  επιλογή «Λειτουργία τεστ» δίνει μία προσπάθεια ανά ερώτηση και δείχνει τη
  σωστή απάντηση. Χωρίς αυτήν, το παιδί δοκιμάζει ξανά.
- Το αποτέλεσμα (σκορ και ανασκόπηση) αποθηκεύεται στον πίνακα `GameResult`
  (πεδία `gameLabel`, `details`) και φαίνεται στην καρτέλα «Αποτελέσματα» του
  μαθήματος.

### Πώς είναι φτιαγμένο

Ο δημιουργός και ο αναπαραγωγέας είναι ένα αυτόνομο αρχείο
`public/ergastiri/index.html` που ανοίγει μέσα σε iframe της ίδιας προέλευσης
(`ActivityFrame`) και μιλά με τη σελίδα μέσω `postMessage`. Το αρχείο μπορεί να
τρέξει και μόνο του, χωρίς εφαρμογή (ανοίγεις κατευθείαν το `index.html`).
Κάθε τύπος δραστηριότητας δηλώνεται με `registerType(...)` μέσα στο αρχείο. Για
να προσθέσεις νέο τύπο, πρόσθεσε το κλειδί του και στο `src/lib/activityTypes.ts`.
